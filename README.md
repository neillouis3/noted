# Noted

🌐 **Live Demo:** https://noted-six-wheat.vercel.app

I wanted a note-taking app that was simple, fast, and free from unnecessary features. Most note apps I tried felt cluttered or overly complex for basic note-taking, so I built Noted to provide a clean and distraction-free experience. The goal was to create something that makes capturing ideas, reminders, and tasks effortless while maintaining a modern and responsive design across all devices.

## Features

- Create, edit, and delete notes
- Clean and intuitive user interface
- Responsive design for desktop and mobile devices
- Real-time note management
- Fast and lightweight user experience
- Organized note storage and retrieval

## Tech Stack

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Vercel** (Deployment)
